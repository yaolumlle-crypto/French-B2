# French B2 one-year study site

Static site: 52-week plan, day-by-day learning flow with instant quiz feedback and an error log,
pronunciation, grammar (A1-B2), 2659 vocabulary entries, 40 dialogues, DELF B2 exam prep,
and a Chinese / English / French interface switch.

Entry point: index.html

Deploy on GitHub Pages: Settings -> Pages -> Source: Deploy from a branch -> main -> / (root).
